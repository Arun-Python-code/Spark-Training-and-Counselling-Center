# Spark Training and Counselling Center for Youth

## About the Project

This is a real-world company project website developed as part of my internship.

I contributed to the design and development of the website, focusing on creating a modern, responsive, and user-friendly interface for the Spark Training and Counselling Center for Youth.

The website presents the organization's training programs, counselling services, activities, internship opportunities, trainee programs, and gallery.

## Features

- Responsive website design
- Modern and user-friendly UI
- Home section
- About Us section
- Gallery section
- Counselling services
- Internship section
- Trainee Program section
- Contact section
- Responsive navigation
- Image gallery with overlay content

## Technologies Used

- HTML5

- Bootstrap5
- JavaScript
- Responsive Web Design
- Git & GitHub

The purpose of this website is to provide information about Spark's youth-focused training, counselling, therapy, internship, and community activities in a clear and engaging way.
